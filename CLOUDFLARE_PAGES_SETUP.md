# Cloudflare Pages Deploy (Next.js App Router)

## Build settings (recommended)
- Framework preset: Next.js
- Build command: `npx @cloudflare/next-on-pages@1`
- Build output directory: `.vercel/output/static`

## If you hit runtime errors
Enable compatibility flag: `nodejs_compat` in your Pages project settings.

## Local run
```bash
npm install
npm run dev
```
